# AQSMS Pi Server API Contract

All endpoints expect and return JSON. Endpoints returning 401/400/500 will return an error object `{"error": "message"}`.
Timestamps are expected in UTC ISO-8601 format (e.g., `2026-10-07T15:30:57Z`).
Units: pH (unitless), temperature_c (°C), dissolved_oxygen_mg_l (mg/L).
All numeric fields can be `null`.

## Unauthenticated Endpoints

### `GET /health`
Returns system health and current time.
**Response**:
```json
{
  "status": "ok",
  "timestamp": "2026-10-07T15:30:57Z"
}
```

### `POST /auth/login`
Authenticates a user and returns a JWT token.
**Request**:
```json
{
  "username": "farmer_joe",
  "password": "securepassword123"
}
```
**Response (200)**:
```json
{
  "token": "eyJ0eXAi...",
  "display_name": "Joe Farmer"
}
```
**Error (401)**: `{"error": "Invalid username or password"}`

## Authenticated Endpoints (Requires `Authorization: Bearer <token>`)

### `GET /readings/latest`
Returns the most recent reading.
**Response (200)**:
```json
{
  "pond_name": "Test Pond 1",
  "reading": {
    "timestamp": "2026-10-07T15:30:00Z",
    "ph": 7.2,
    "temperature_c": 22.5,
    "dissolved_oxygen_mg_l": 6.8
  }
}
```
If no readings:
```json
{
  "pond_name": "Test Pond 1",
  "reading": null
}
```

### `GET /readings?limit=N`
Returns a list of recent readings. Default limit is 50.
**Response (200)**:
```json
{
  "readings": [
    {
      "timestamp": "2026-10-07T15:30:00Z",
      "ph": 7.2,
      "temperature_c": 22.5,
      "dissolved_oxygen_mg_l": 6.8
    }
  ]
}
```

### `GET /alerts?limit=N`
Returns recent alerts.
**Response (200)**:
```json
{
  "alerts": [
    {
      "timestamp": "2026-10-07T15:30:00Z",
      "parameter": "ph",
      "value": 4.5,
      "threshold": "< 6.0",
      "status": "unsafe",
      "message": "pH level dropped below safe minimum."
    }
  ]
}
```

### `GET /thresholds`
Returns the current configured safety thresholds.
**Response (200)**:
```json
{
  "approved": true,
  "ph": {
    "safe_min": 6.5,
    "safe_max": 8.5,
    "warn_min": 6.0,
    "warn_max": 9.0
  },
  "temperature": {
    "safe_min": 20.0,
    "safe_max": 30.0,
    "warn_min": 18.0,
    "warn_max": 32.0
  },
  "dissolved_oxygen": {
    "safe_min": 5.0,
    "safe_max": null,
    "warn_min": 4.0,
    "warn_max": null
  }
}
```
Values can be `null` if not configured. `approved` is a boolean.

## ESP32 Ingestion Endpoints (Requires `X-API-Key: <key>`)

### `POST /esp32/readings`
Records a new sensor reading.
**Request**:
```json
{
  "timestamp": "2026-10-07T15:30:57Z",
  "ph": 7.2,
  "temperature_c": 22.5,
  "dissolved_oxygen_mg_l": null
}
```
**Response (201)**: `{"message": "Reading created"}`

### `POST /esp32/alerts`
Records a new alert generated by the ESP32.
**Request**:
```json
{
  "timestamp": "2026-10-07T15:30:57Z",
  "parameter": "temperature",
  "value": 35.5,
  "threshold": "> 32.0",
  "status": "warning",
  "message": "Temperature warning threshold exceeded."
}
```
- `parameter` must be one of: `ph`, `temperature`, `dissolved_oxygen`.
- `status` must be one of: `warning`, `unsafe`.
**Response (201)**: `{"message": "Alert created"}`
**Error (400)**: `{"error": "Invalid status value"}` if status is unrecognized.
